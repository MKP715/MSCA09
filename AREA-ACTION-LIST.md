## How to send information to the webmaster

- E-mail **webmaster@msca09aa.org** with the file attached. One topic per e-mail.
- Names: **first name + last initial** only. Contacts: **role mailboxes** (…@msca09aa.org) only — never a personal e-mail or phone, and no personal details in group e-mails.
- PDFs: first clear your name from the file properties (Word/Excel *File → Info → Inspect Document*, or *File → Info → Properties*; Pages: clear the author), then *Save as PDF*, not "Print to PDF".
- Never put sobriety dates, phone numbers or home addresses in documents meant for the website ("Sobriety anniversaries were celebrated." is enough).
- Events go straight into the Area Google Calendar (section 4), not to the old website.
