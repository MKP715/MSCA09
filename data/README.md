# data/ — the website's content

Every word, person, district, committee and document on the site comes from the files in this
folder. Meetings and events come from the Area's Google Calendar instead, mirrored into
`calendar.ics`.

**How to edit:** open a file on github.com, press the pencil icon, change it, and press *Commit changes*.
The site rebuilds in about two minutes. Details are in the main [README](../README.md#everyday-updates).

General rules for every file:

- The first row is the header. Don't rename or remove columns.
- Rows that start with `#` are notes for editors, and the site ignores them. Most files start with a few
  of these notes explaining their columns: read them before adding a row.
- Every row has as many values as the header (keep the trailing commas of a short row). A value that
  contains a comma, a line break or a `"` is wrapped in "double quotes", and a `"` inside it is written twice (`""`).
  A broken row is reported during the build and stops the site check until it is fixed, so no data is lost silently.
- Save as **UTF-8** (Excel: *CSV UTF-8*).
- Columns ending in `_en` / `_es` hold English and Spanish. If the Spanish cell is empty, the English text is shown.
- `{panel}`, `{years}` and `{previous_panel}` in any text are filled in from `settings.csv`; other words in
  `{braces}` are filled in by the page that uses them. Keep them as they are, in both languages.
- `color` columns take a palette name: `ocean iris coral sun sage copper blush lilac sea`
  (or a Tailwind colour such as `teal`, `rose`, `amber`).
- `icon` columns take a [Lucide icon](https://lucide.dev/icons) name, e.g. `calendar-days`, `map`, `users`. The site adds one name of its own: `service-triangle`, Lucide's triangle pointing down, for A.A.'s upside-down service triangle.
- Dates are `YYYY-MM-DD`. `start` / `end` columns make a row appear and disappear on those days.
- Lists inside one cell are separated with `;`.
- Long text cells accept Markdown: `**bold**`, `[link text](https://…)`, and `- ` for list items.
- **Anonymity:** first name + last initial only, and role e-mail addresses only (see the main README).

## The files

| File | What it controls | Change it when |
|---|---|---|
| `settings.csv` | Panel number and years (`panel`, `panel_years`, `previous_panel`), mailing address, Zelle details, role e-mails (`email_webmaster`, `email_contributions`, `email_secretary`), the calendar id, the GitHub repository, the site address for local builds, and for the online finance forms `mileage_rate` (dollars per mile), `budget_request_year` and `budget_request_deadline` (YYYY-MM-DD). `drive_folder_id` stays **empty**: the Drive folder id is the repository **secret** `DRIVE_FOLDER_ID` (*Settings → Secrets and variables → Actions → Secrets*, next to the `GOOGLE_API_KEY` secret), so it is never published. Never a variable: variables are printed in the public build logs, and the build reads only the secret | the panel rotates; an address changes |
| `nav.csv` | The menu (top items and their dropdown entries) and the footer links | a page is added |
| `text/*.csv` | **Every heading, sentence and button** in English and Spanish (`key`, `en`, `es`, `notes`). There is one file per section of the site: `common`, `home`, `calendar`, `districts`, `committees`, `people`, `documents`, `service`, `content`, `forms` (the online expense and budget forms at `/service/forms/`), and `triangle` (the words of the upside-down service triangle that Home, About, Districts and How service works all draw, and the "why 22 trustees" note). `common.csv` also holds `search.kw./page-address/` rows (extra words for the site search); `calendar.csv` holds `calendar.title_es.<slug>` and `calendar.note_es.<slug>` rows (Spanish titles and notes until Google Calendar has `Título:` / `Nota:` lines). | wording changes |
| `announcements.csv` | Home-page announcements with `start`/`end` dates, shown in `event_date` order (soonest event first); `pin` = `yes` highlights one | there's news |
| `hero.csv` | Home-page banner photos, with their alt text and photo credits. `file_mobile` = an optional upright photo for phones; `position_desktop` / `position_mobile` = the point of the photo that stays in view | new photos |
| `home-links.csv` | The quick-action tiles on the home page | rarely |
| `event-types.csv` | Calendar categories (`MSCA09\|<Type>\|…`): label, colour, icon, group, whether a type counts as a meeting or an event, and `default_language` (e.g. `Bilingual` for interpreted Area meetings) | a new kind of calendar entry |
| `districts.csv` | One row per district: cities, counties, about text, contacts, website, map pin, `subdistricts_es` (Spanish names of the sub-districts). `title_area_en` / `title_area_es` (optional) name the place after the district in search-result titles; empty = its counties. The `meeting_*` columns (and `venue`, `address`, `room`, `city`, `zip`, `zoom_*`) are used when the calendar has no entry for that district, and to fill in a venue name or ZIP the calendar leaves out. `meeting_override` = `yes` makes them win over the calendar while the calendar entry is known to be wrong — clear it once the calendar is fixed (the build log says when they agree). | a district asks |
| `gsr-schools.csv` | The districts' GSR Schools and new-GSR orientations — the "GSR School" section of a district page and the list on `/committees/gsr-school/`. `kind` = `school` / `orientation` (what it is, what is studied) or `link` (the district's own GSR material). When it meets: `calendar_uid` (its own Area calendar entry: day, time, Zoom, flyer and Add to calendar come from there), else `start`/`end` (held before the district meeting, on its days and at its place), else the `when_*`/`where_*` words (`when_*` = its own day, with `start`/`end` as its time; in a `calendar_uid` or `start`/`end` row, `where_*` is a short note under the place). Each card's contact is the district's GSR School Chair from `trusted-servants.csv` when one is named. Role e-mails only; check a PDF before linking it. | a district starts, moves or stops its GSR School |
| `trusted-servants.csv` | Every trusted servant: officers, committee chairs, DCMCs and district officers, for this panel and the last. `status` = `Filled` / `Open` (vacant, `name` empty) / `Unknown` (not provided yet — the district has not reported who holds the seat or that it is open: `name` and `email` empty; the site shows "Not provided yet") / `Unnamed` (role mailbox only) / `Unconfirmed` (the name is shown "to be confirmed") / `Completed` (an ad-hoc committee that has finished). District rows: exactly six per active district — DCMC, Alternate DCMC, Secretary, Treasurer, Registrar, GSR School Chair (`position_sort` 1–6); Districts 20–25 label the first two `DCMC (MCD)` and `Alternate DCMC (Alt. MCD)`. | elections, resignations |
| `committees.csv` | Every committee, school, subcommittee and officer role: purpose, activities, how to get involved, e-mails, aa.org page, `calendar_match` keywords | a chair asks |
| `committee-resources.csv` | Guidelines, aa.org workbooks, pamphlets and links on each committee page, plus the committee's own website card (kind `website`: the site's name and one line on what is on it; the address is in the `website` column of `committees.csv`) and a standing flyer (kind `flyer`: `url` = the pictures of its pages in `docs/flyers/`, `;`-separated in page order; `pdf` = the printable PDF) and the committee's live working document (kind `log`: a Google Doc or Sheet the committee keeps up to date, linked — never copied — as a card near the top of its page, a header button and a Quick links entry). `status` = `hidden` keeps any row in the file but off the site (e.g. the Technology Committee's work log: set its `status` from `current` to `hidden`) | new guidelines, a committee website, flyer or work log |
| `finance-forms.csv` | The online finance forms (`/service/forms/`): every choice, column and line of the Expense Reimbursement and Annual Budget Request forms in the paper forms' order (`section` = `official` / `send` / `line` / `by` / `column` / `both` / `english` / `spanish` / `officer` / `item`), the official PDF/Word document ids, where each form is e-mailed (committee slug), and `paper_rows` (how many numbered lines a budget line has on paper; the printed copy adds empty lines up to it while the page has room). The mileage rate and the budget year and deadline are in `settings.csv`. | a new paper form is published |
| `prf/` | The Pacific Regional Forum 2028 pages (`/service/prf-2028/`), which Area 09 hosts: `forum.csv` (dates, hotel, room block, registration link, the host committee's address — the forms write to it), `positions.csv` (the ten chair positions; `status` = `open` / `filled`), `schedule.csv`, `shifts.csv`, `faq.csv`, `areas.csv` (the 15 Pacific Region areas), `places.csv` (airports, things to do, map pins), `timeline.csv`, `cards.csv` (the short lists and card grids) and `links.csv`. Wording: `text/prf.csv`. | G.S.O. publishes registration or the program; the Area confirms a chair; the dates or hotel change |
| `documents/` | The document library, one row per document, split into small files: **`current.csv`** (new documents go here), `archive-….csv` (by year) and **`held.csv`** (documents kept off the site — never delete its rows and never empty it). `publish` = `yes` / `review` / `no`. Rows that are not published carry **no links** (`url` empty, no Drive or old-site address): the public repository must not open the held files. Full guide: [`scripts/README-documents.md`](../scripts/README-documents.md). | a document is added |
| `archives/collections.csv` | The Area 09 Archives Committee's Google Drive folders and files (from msca09aa-archives.org) and how the library shows each: `mode` = `files` (every file on its shelf, tagged "Area 09 Archives"), `link` (one entry under "The Archives' collections" on `/documents/archive/`) or `off`. `archives/files.json` is their file list — written by the build once a day (`scripts/archives-index.mjs`); do not edit it. | the Archives add a collection |
| `archives/overrides.csv` | Corrections for single Archives files whose file name gives a wrong date or a poor title (`drive_id`, `date`, `title_en`, `title_es`, `notes`). To keep one Archives file out of the library, add its id to `flyer-holds.csv` instead. | a scan shows the wrong date or title |
| `document-categories.csv` | The shelves of the document library (`/documents/<key>/`). `expect_yearly` = `yes` shows a "not posted yet — write to `gap_email`" line for a missing year (the minutes). | rarely |
| `recordings.csv` | The Zoom meeting recordings (audio only) a committee page lists and plays — today `/committees/technology/#recordings`: one row per `.m4a` file in the Drive folder `MSCA09AA/Zoom Recordings/` (`drive_id`, `committee`, `series`, `date`, `time` (Pacific), `part`, `session`, `track` = `main` / `es` / `en` (interpretation), `duration`, `size_mb`, `show`, `title_en`, `title_es`, `path`, `notes`). `show` = `no` hides one. Filled by `npm run drive:recordings` (`scripts/recordings.py`, on a computer with Google Drive for Desktop and FFmpeg): it adds new files, never changes a filled cell or deletes a row, and adds recordings shorter than 3 minutes with `show` = `no`. Only the audio is ever listed — never the videos, transcripts or chats | after Area meetings are recorded; to hide a recording |
| `recording-series.csv` | The meetings those recordings belong to (one row per meeting folder in `Zoom Recordings/<month>/`): `key`, `folder` (the Drive folder's name), `name_en`, `name_es` (the name and filter button on the page), `link` (a committee slug or a page of this site), `sort` | a new meeting is recorded (the script adds a row named after the folder: give it proper names) |
| `drive-folders.csv` | For the optional automatic Drive listing: which `docs/` folders are listed, and as what | a Drive folder is added |
| `motions.csv` | Motions and their status (new business → passed / failed …) | after every ASC / Assembly |
| `gsc.csv` | General Service Conference, PRAASA and Forum dates and themes (Delegate's corner) | each Conference cycle |
| `glossary.csv` | Service words in English and Spanish (GSR = RSG, DCMC = CMCD …) | anyone can add |
| `central-offices.csv` | Central offices, intergroups and hotlines: public phone numbers, websites, hours | a number changes |
| `organizers.csv` | The organizations that a Google Calendar entry's `Organizer:` line can name (intergroups, conventions, roundups, G.S.O.'s General Service Board, the Area): `name_en`, `name_es` (only an official Spanish name; empty = the English one on Spanish pages), `url` (the organization's own website), `also` (other names an `Organizer:` line may use, `;`-separated), `checked`, `source`. Search engines read the row as the event's organizer, and the event page shows "Hosted by". Never a person. | a new host's event goes in the calendar; a host's website changes |
| `resources.csv` | Links on the Resources, Newcomers, Contribute and Policy pages (`show` = `no` hides a row; the Zelle QR code stays hidden until the Treasurer has test-scanned it). Group `contribute-files` holds the files /contribute/ uses itself: the Zelle QR code, the contributions flyer PDF (`contribute-flyer`) and pictures of its English and Spanish pages (`contribute-flyer-pages`: `url` / `url_es`) | links change |
| `faq.csv` | Questions and answers on the Newcomers and Contribute pages | rarely |
| `redirects.csv` | Old msca09aa.org (WordPress) addresses and the page each one forwards to: `old_path`, `new_path`, `note`. An `old_path` ending in `*` covers every address that starts with it. Never the address of a page of this site. The old address of a renamed or moved event (`/events/…`, `/es/events/…`) gets a forwarding page too; a row that forwards to an event page the calendar no longer has forwards to the Events page (`/calendar/`) instead (the build warns). | an old link turns up; an event is renamed |
| `link-fixes.csv` | Web addresses typed into Google Calendar that the site must not link to as they are: `match` (a site's name such as `aadistrict17.info`, which covers its sub-sites too, or the start of an address, beginning with the site's name, such as `msca09aa.org/wp-content/` — no `*`), `replace_with` (the full `https://` address to link instead; empty = no link at all), `since`, `note`. Applied to every link of every calendar entry (pages, Add to calendar, `.ics` files, `events.json`); the first matching row wins. `npm run check:calendar` names the entries to clean in Google Calendar, and the site check stops if a data file still links to a site whose `replace_with` is empty. | a linked site is hacked; an old file moves |
| `flyer-holds.csv` | Google Drive flyers and PDFs the site must **not** show, because they print personal details: `drive_id`, `reason` (what kind of detail — never the detail itself), `held_on`, `notes`. Filled by the weekly flyer check or by hand. Applies to calendar flyers and to published documents (they leave the library quietly; the build never stops for a hold). To release a file: in Drive, *Manage versions → Upload new version* with the details removed, then delete its row (see the main README, "Flyers and PDFs on hold"). | a flyer is fixed |
| `media-review.csv` | Written by the weekly **Check flyers and PDFs for personal details** workflow: each Drive file it has read (`drive_id`, `checked_on`, `result`, `notes`). `result` = `clean`, `hold: …` (also in `flyer-holds.csv`), `cleared` (a person looked: false alarm) or `error: …` (tried again after 30 days). Delete a row to have that file read again. | a false alarm (set `cleared`) |
| `contact-allowlist.csv` | Role mailboxes on Gmail/Outlook and public phone lines that the anonymity check allows (`value`, `kind` = `email` / `phone` / `email-approved`, `reason`). A free-mail address is accepted only when its name says which role it serves. `email-approved` = a servant's own address published at an explicit, dated request (see the file's comment rows); it must be that servant's `email_alt` in trusted-servants.csv. **Needs a reviewer** (`.github/CODEOWNERS`). | a new role mailbox |
| `name-allowlist.csv` | Words that look like a full name but are not a member's (venues, places, book titles, authors, Class A trustees, GSO staff): `phrase`, `reason`. Never a member's real name. **Needs a reviewer** (`.github/CODEOWNERS`). | the check mistakes a place for a name |
| `calendar.ics` | A copy of the Google Calendar. **Don't edit it.** The build refreshes it automatically, and saves the new copy only when `scripts/check-calendar.mjs --all` finds no personal e-mail address or phone number in any entry (the copy is public history); otherwise it keeps the last clean copy and warns. | never |
| `office-event-sources.csv` | How each central office's events are read from its website (one row per key of `central-offices.csv`): `short` (its badge), `adapter` (`tribe`, `aanoc`, `tvco`, `watch`, `shared`, `none`), `feed`, `events_page` (linked from its card on `/calendar/central-offices/`), `import` = `yes` / `no`, `crawl_delay`, `options` (`k=v; k=v`; `card=pictures` or `card=list` for an office that is only watched). See the main README, "Central-office events". | an office changes its website, or asks us to stop |
| `central-office-overrides.csv` | Corrections for single imported events: `id` (`co-<office>-…`), `action` = `hide` / `show` / `same-as` (value = an Area event's page slug) / `type` / `title`, `value`, `until` (YYYY-MM-DD, optional), `notes`. | an imported event is wrong or a duplicate |
| `central-office-events.json` | The central offices' upcoming events, read from their websites once a day by `scripts/office-events.mjs` (cleaned of personal details). **Don't edit it** — use the overrides file. Committed by the build only when `node scripts/office-events.mjs --check` passes. | never |
| `office-flyer-review.csv` | Written by the flyer check of the central offices' flyers (`scripts/check-media.mjs --office-flyers`): `url`, `sha256` (the file that was read), `checked_on`, `result` (`clean`, `hold: e-mail`, `hold: sobriety`, `hold: password`, `error: …` — `error: changed` when the office replaced the file, `error: robots` when its robots.txt does not allow it — or `cleared` after a person looked), `notes`. A flyer is shown only while its row says `clean` or `cleared` for the same file; checked flyers are read again every 14 days. | a false alarm (set `cleared`) |
| `generated/` | Created during the build (Drive listing); not committed | never |
